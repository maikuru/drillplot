drillplot

Pickleball drill diagrams on a to-scale court, exported as SVG that carries its own editable source.

Source on GitHub

Examples

Each drawn with renderSvg() alone. Open one in the editor above to change it. The last two use the 0.2 additions: a keyed legend, a line to split-step on, colored and dashed paths, a start position, open space, roles under players, either-or shots, a printed caption and two courts.

Events

The editor fires change on every edit and save from its Save button (or Ctrl or Cmd + S).
